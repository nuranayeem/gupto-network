GUPTO PHASE 03L — INVISIBLE WHEEL SCROLL

Base required: Phase 03K

Fixes
- Completely hides the Story Studio scrollbar in Chrome, Edge, Firefox and compatible browsers.
- Keeps the settings column scrollable with mouse wheel and trackpad gestures.
- Wheel scrolling works while the pointer is over either the preview or the settings area.
- Preserves mobile touch scrolling and all Phase 03K viewport safeguards.

Install
1. Extract this ZIP into the project root and replace matching files.
2. Run: npm run build
3. Run: npm run dev

Database migration: Not required.

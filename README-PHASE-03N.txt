GUPTO PHASE 03N — FINAL TYPOGRAPHY AND DYNAMIC MENUS

Base required: Phase 03M

Polish
- Enlarges and clarifies Story Studio headings, labels, helper text, inputs, buttons and setting values.
- Replaces every native Story Studio dropdown with one Apple-inspired custom menu system.
- Adds rounded translucent menus, soft blur/shadow, selected checkmarks, hover feedback and smooth opening motion.
- Menus automatically open upward when there is not enough room below.
- Long Font menus support independent mouse-wheel scrolling.
- Supports click-outside close, Escape, Enter, Space and Arrow-key interaction.
- Applies to Font, Place, Audience, Story lifetime and Photo pace.
- Preserves Phase 03M photo None default and Phase 03L invisible wheel scrolling.

Install
1. Extract this ZIP into the project root and replace matching files.
2. Run: npm run build
3. Run: npm run dev

Database migration: Not required.

GUPTO PHASE 03I — CAPTION SAFE WRAP

What changed
- Caption keeps its natural single-line width until it reaches the story canvas safe edges.
- Words no longer split in the middle (for example, "Nayeem" will not become "Nay" + "eem").
- When wrapping is genuinely needed, it happens at normal word boundaries.
- The same rule applies to both the editor preview and the published story viewer.

Install
1. Extract this archive into the project root.
2. Replace the included file when prompted.
3. Restart the development server if it is already running.

Database
- No migration is required for this update.

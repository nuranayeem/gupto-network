GUPTO PHASE 03M — LEAN CAPTION AND PHOTO DEFAULT

Base required: Phase 03L

Changes
- Removes “More text options” from the Caption editor.
- Removes the duplicate Precise size slider.
- Keeps the compact minus/value/plus control as the single 8–72px size interface.
- Removes the Rotation control from the new Story composer while preserving old published Story rendering compatibility.
- Automatically selects Make it yours → None whenever a new photo is chosen.
- Users can still manually select an accent after choosing the photo.
- Preserves invisible mouse-wheel scrolling from Phase 03L.

Install
1. Extract this ZIP into the project root and replace matching files.
2. Run: npm run build
3. Run: npm run dev

Database migration: Not required.

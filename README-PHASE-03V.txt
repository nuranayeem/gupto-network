GUPTO PHASE 03V — MUSIC DURATION PRESETS

Install over Phase 03U:
1. Extract this ZIP into the project root and replace matching files.
2. Run: npm run build
3. Run: npm run dev

Music-only duration options:
- 10 seconds
- 20 seconds
- 30 seconds
- 1 minute
- None · Full music

Notes:
- None is selected by default and plays the complete track.
- If a track is shorter than the selected preset, its full available duration is used.
- Photo + Music keeps its existing 20-second selector.
- No database migration is required.

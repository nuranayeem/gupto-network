GUPTO PHASE 04S — FACEBOOK-STYLE SEPARATE OWNER STORY PROFILE

Base: Phase 04R

Changes:
- Keeps the first owner card dedicated to creating a new Story.
- Creates a separate active owner Story profile after publishing.
- Places the active owner profile in the Story track like every other profile.
- Opens the Story viewer from the active owner profile.
- Keeps Viewer-matched photo and music previews on the active owner profile.
- Preserves all existing Story API, viewer, duration and composer behavior.

Install:
1. Extract this ZIP into the project root and replace matching files.
2. Run: npm run build
3. Run: npm run dev
4. Hard-refresh the browser.

Database migration: Not required.

GUPTO PHASE 02S — MEDIA CONTROL POLISH

Install on top of Phase 02R:
1. Copy the included components and app folders into the project root.
2. Replace files when prompted.
3. Run: npm run build
4. Run: npm run dev

What changed:
- Added removal controls for selected photo/video and music.
- Added a None accent option.
- None uses only the media-matched blurred background.
- Color options use their selected accent background.
- Choose Media uses a Font Awesome Photo Film icon.
- Edit & Resize uses a Font Awesome Crop Simple icon.

Database migration: Not required.

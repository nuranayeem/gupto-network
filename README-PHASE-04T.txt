GUPTO Phase 04T — Latest Story Preview on Create Card

Base: Phase 04S

Changes:
- The fixed Create story card now previews the user's latest published Story.
- Photo, video and music previews use the same latest Story data as Your story.
- Create story still opens the Story composer.
- The separate Your story card remains available and opens the Story viewer.
- No database migration is required.

Install:
1. Apply this ZIP over Phase 04S at the project root.
2. Run: npm run build
3. Run: npm run dev
4. Hard refresh the browser with Ctrl + Shift + R.

GUPTO PHASE 02Q — MATCHED BLUR MEDIA BACKGROUND

Features
- Removes the default purple/black empty background around fitted media.
- Uses an enlarged, softly blurred copy of the same image or video.
- Keeps the main foreground media sharp and readable.
- Works in Media Lab, Story composer preview and published Story viewer.
- Supports Photo, Video and Photo + music media.
- No database migration is required.

Install
1. Install corrected Phase 02P first.
2. Extract this ZIP into the gupto-network project root and replace matching files.
3. Run:
   npm run build
   npm run dev

GUPTO PHASE 03F — DISTINCT & LUXURY CAPTION FONTS

Install on top of Phase 03E:
1. Copy app, components, and types into the project root and replace matching files.
2. Run: npm run build
3. Run: npm run dev

What changed:

- Modern now uses a neutral minimal Inter treatment.
- Poppins now has a visibly geometric character.
- Added Social Impact with a condensed uppercase display style.
- Added Luxury Signature using Cormorant Garamond for a premium editorial look.
- Existing saved caption styles remain compatible.

No database migration is required.

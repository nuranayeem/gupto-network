GUPTO PHASE 03E — CURATED CAPTION STYLES

Install on top of Phase 03D:
1. Copy app, components, and types into the project root and replace matching files.
2. Run: npm run build
3. Run: npm run dev

What changed:
- Caption backgrounds are now limited to None, Glass, and Solid.
- Added a curated font set for clean, social, friendly, editorial, creator, casual, fun, and tech captions.
- Added custom color pickers for caption text and Solid background fill.
- Existing preset colors remain available for quick selection.
- Legacy Highlight values are safely displayed as None.

No database migration is required for this update.

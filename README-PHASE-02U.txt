GUPTO PHASE 02U — USER-PROVIDED MEDIA ICONS

Install on top of Phase 02T:
1. Copy the included components, app and public folders into the project root.
2. Replace files when prompted.
3. Run: npm run build
4. Run: npm run dev

What changed:
- Add or Change Media now uses the supplied photo-plus icon.
- Edit & Resize now uses the supplied increase/resize icon.
- Both PNG assets are rendered as theme-aware CSS masks.
- Icons keep transparent backgrounds and inherit Gupto purple automatically.

Database migration: Not required.

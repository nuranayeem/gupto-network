GUPTO PHASE 02R — UNIFIED MEDIA STORY FLOW

Install on top of Phase 02Q:
1. Copy the included components and app folders into the project root.
2. Replace files when prompted.
3. Run: npm run build
4. Run: npm run dev

What changed:
- Photo, Video, Music and Photo + Music mode cards are replaced by one Media picker.
- The separate "2. Add what you love" section is removed.
- Media type is detected automatically.
- Users may select a photo/video and music together, or add them one after another.
- Existing Edit & Resize and matched-blur background behavior remains intact.

Database migration: Not required.

GUPTO PHASE 02W — DEFAULT FIT MEDIA

Install on top of Phase 02V:
1. Copy the included components, types and app folders into the project root.
2. Replace files when prompted.
3. Run: npm run build
4. Run: npm run dev

What changed:
- Newly selected photos and videos now open in Fit mode by default.
- Reset Everything also returns media to Fit mode.
- The Fit control is now on the left and Fill is on the right.
- The story API safely defaults missing mediaFit values to Fit.
- Existing saved story settings remain unchanged.

Database migration: Not required.
